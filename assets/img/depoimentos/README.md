# Fotos dos depoimentos da Aset Life Community

Coloque nesta pasta as imagens autorizadas para a seção de depoimentos da página `/grupo/`.

Use estes nomes de arquivo (ou altere os caminhos no HTML em `grupo/index.html`):

- `depoimento-01.webp`
- `depoimento-02.webp`
- `depoimento-03.webp`

Os caminhos usados no HTML são relativos à página:
- `../assets/img/depoimentos/depoimento-01.webp`
- `../assets/img/depoimentos/depoimento-02.webp`
- `../assets/img/depoimentos/depoimento-03.webp`

Prefira imagens WebP otimizadas, em boa resolução e com autorização expressa para publicação. Não use fotos de terceiros sem consentimento. Atualize também o texto, nome/iniciais e identificação de cada cartão com o relato real correspondente. Remova os textos entre colchetes antes de publicar depoimentos definitivos.

Os cartões são modelos de preenchimento; não representam depoimentos reais enquanto não forem substituídos.
